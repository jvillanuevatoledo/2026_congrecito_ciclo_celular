# **ANÁLISIS DE CICLO CELULAR POR CITOMETRÍA DE FLUJO**

Repositorio oficial del taller práctico enfocado en el análisis e interpretación del **ciclo celular** mediante citometría de flujo utilizando **software de análisis manual**.

## 📂 Estructura del Repositorio

* **`datos/`**: Archivos de datos de ejemplo (formatos estándar `.fcs`) listos para importar en tu software de análisis.
* **`manuales/`**: Guías paso a paso, manuales de usuario y protocolos detallados en formato PDF o Markdown.
* **`templados/`**: Plantillas, layouts o espacios de trabajo exportados del software de análisis para estandarizar las compuertas # Taller Práctico: Análisis de Ciclo Celular por Citometría de Flujo

## 🛠️ Requisitos y Herramientas

Para seguir las prácticas de este taller, necesitarás contar con un programa de análisis manual de citometría de flujo instalado en tu equipo, tales como:
* [floreada.io](https://floreada.io/analysis)
* Herramientas de libre acceso o versiones de prueba/educativas compatibles con archivos `.fcs`.

También se recomienda tener instalado un lector de archivos PDF y una hoja de cálculo (como Microsoft Excel o [Google Sheets](https://sheets.google.com)) para tabular los porcentajes obtenidos.(*gating*).
